## Sources

### Week 1

- [AI Agent Evaluation](https://deepeval.com/guides/guides-ai-agent-evaluation) — Learn how to evaluate an agent's reasoning, tool calls, and task completion using end-to-end, trajectory-based, and component-level metrics.
- [How context windows work](https://www.youtube.com/watch?v=-uW5-TaVXu4) — Explore what fills an AI coding agent's context window, why long conversations cause lost-in-the-middle problems, and how to manage context effectively.
- [Understand how LLM tokens work](https://www.youtube.com/watch?v=nKSk_TiR8YA) — Understand input and output tokens, how tokenizers build vocabularies, and why tokenization affects usage costs differently across model providers.
